Derrick Adjei — Portfolio

I built this site to put my work online and show what I can do on the frontend.

Stack

  • Next.js 15 (App Router) + React 19 + TypeScript
  • Tailwind CSS + shadcn/ui-style primitives
  • Framer Motion + Lucide Icons
  • GitHub REST API (build-time fetch)
  • Markdown articles
  • Mermaid architecture diagrams
  • Static export → GitHub Pages (no Vercel required)

Features

  • Sticky navigation, dark mode default, theme switcher
  • Command palette (⌘K / Ctrl+K) with project search
  • Hero with typing animation + headshot placeholder
  • About, skills, experience timeline, featured projects
  • Project detail pages with architecture / pipeline diagrams
  • Auto-loaded GitHub repos (featured list + featured topic)
  • GitHub stats, languages, events, contribution heatmap
  • Markdown blog with automatic listing
  • Architecture showcase
  • Contact form (mailto), resume download
  • SEO: robots, sitemap, Open Graph, Twitter cards, JSON-LD
  • Scroll + reading progress indicators

Quick start

npm install
npm run dev

Open http://localhost:3000.

Production build (static)

npm run build

Static files are written to out/.

Preview locally:

npx serve out

For GitHub Pages project-site base path locally:

BASE_PATH=/Portfolio npm run build

GitHub Pages deployment

This repo includes .github/workflows/deploy.yml.

One-time setup

  1. Push this repository to GitHub (recommended name: Portfolio).
  2. In the repo: Settings → Pages → Build and deployment → Source: GitHub Actions.
  3. Push to main (or run the workflow manually).
  4. Site URL will be:
    • Project site: https://<user>.github.io/Portfolio/
    • User site: use a username.github.io repo (basePath becomes empty automatically)

next.config.ts sets basePath from GITHUB_REPOSITORY during CI.

Optional: create a repository variable BASE_PATH if you need an explicit override (advanced).

Optional: higher GitHub API rate limits

The default GITHUB_TOKEN in Actions is already passed to the build. For local builds against the API, you can set:

export GITHUB_TOKEN=ghp_xxx
npm run build

Customize

What Where
Name, bio, links, nav src/lib/site.ts
Skills / radar src/lib/skills.ts
Experience timeline src/lib/experience.ts
Project case studies src/lib/projects.ts
Articles content/articles/*.md
Headshot replace public/images/headshot-placeholder.svg
Resume PDF replace public/resume/Derrick_Adjei_Resume.pdf
LinkedIn URL src/lib/site.ts → links.linkedin

Auto-feature new projects

  1. Add GitHub topic featured to a repository, or
  2. Add the repo name to siteConfig.github.featuredRepos, and
  3. Optionally add a case-study entry in src/lib/projects.ts.

Redeploy (push to main) to refresh build-time GitHub data.

Project structure

src/
  app/                 # Routes (static-export compatible)
  components/          # UI, layout, sections, diagrams
  lib/                 # Site config, GitHub client, content loaders
content/articles/      # Markdown blog posts
public/                # Images, resume, OG assets
.github/workflows/     # GitHub Pages deploy

Accessibility & performance notes

  • Semantic landmarks, keyboard-accessible command palette
  • Reduced-motion-friendly subtle Framer Motion transitions
  • Static export + optimized SVG assets for fast Lighthouse scores
  • Images use unoptimized for GitHub Pages compatibility
