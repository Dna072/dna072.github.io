1a:T132f,<h1>Derrick Adjei — Portfolio</h1>
<p>I built this site to put my work online and show what I can do on the frontend.</p>
<h2>Stack</h2>
<ul>
<li>Next.js 15 (App Router) + React 19 + TypeScript</li>
<li>Tailwind CSS + shadcn/ui-style primitives</li>
<li>Framer Motion + Lucide Icons</li>
<li>GitHub REST API (build-time fetch)</li>
<li>Markdown articles</li>
<li>Mermaid architecture diagrams</li>
<li>Static export → GitHub Pages (no Vercel required)</li>
</ul>
<h2>Features</h2>
<ul>
<li>Sticky navigation, dark mode default, theme switcher</li>
<li>Command palette (<code>⌘K</code> / <code>Ctrl+K</code>) with project search</li>
<li>Hero with typing animation + headshot placeholder</li>
<li>About, skills, experience timeline, featured projects</li>
<li>Project detail pages with architecture / pipeline diagrams</li>
<li>Auto-loaded GitHub repos (featured list + <code>featured</code> topic)</li>
<li>GitHub stats, languages, events, contribution heatmap</li>
<li>Markdown blog with automatic listing</li>
<li>Architecture showcase</li>
<li>Contact form (mailto), resume download</li>
<li>SEO: robots, sitemap, Open Graph, Twitter cards, JSON-LD</li>
<li>Scroll + reading progress indicators</li>
</ul>
<h2>Quick start</h2>
<pre><code class="language-bash">npm install
npm run dev
</code></pre>
<p>Open <a href="http://localhost:3000">http://localhost:3000</a>.</p>
<h3>Production build (static)</h3>
<pre><code class="language-bash">npm run build
</code></pre>
<p>Static files are written to <code>out/</code>.</p>
<p>Preview locally:</p>
<pre><code class="language-bash">npx serve out
</code></pre>
<p>For GitHub Pages project-site base path locally:</p>
<pre><code class="language-bash">BASE_PATH=/Portfolio npm run build
</code></pre>
<h2>GitHub Pages deployment</h2>
<p>This repo includes <a href=".github/workflows/deploy.yml"><code>.github/workflows/deploy.yml</code></a>.</p>
<h3>One-time setup</h3>
<ol>
<li>Push this repository to GitHub (recommended name: <code>Portfolio</code>).</li>
<li>In the repo: <strong>Settings → Pages → Build and deployment → Source: GitHub Actions</strong>.</li>
<li>Push to <code>main</code> (or run the workflow manually).</li>
<li>Site URL will be:
<ul>
<li>Project site: <code>https://&#x3C;user>.github.io/Portfolio/</code></li>
<li>User site: use a <code>username.github.io</code> repo (basePath becomes empty automatically)</li>
</ul>
</li>
</ol>
<p><code>next.config.ts</code> sets <code>basePath</code> from <code>GITHUB_REPOSITORY</code> during CI.</p>
<p>Optional: create a repository variable <code>BASE_PATH</code> if you need an explicit override (advanced).</p>
<h3>Optional: higher GitHub API rate limits</h3>
<p>The default <code>GITHUB_TOKEN</code> in Actions is already passed to the build. For local builds against the API, you can set:</p>
<pre><code class="language-bash">export GITHUB_TOKEN=ghp_xxx
npm run build
</code></pre>
