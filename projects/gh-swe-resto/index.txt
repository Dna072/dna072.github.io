1a:T1109,<h1>Meridian Fusion Cuisine</h1>
<p>Production-grade online ordering and operations platform for Meridian Fusion Cuisine in Uppsala, Sweden. The kitchen starts with Ghanaian plates and will add more meals over time.</p>
<p>This is not a marketing site. It is a modular monolith for menu, cart, guest checkout, customer accounts, payments, delivery, kitchen operations, and administration — hosted on Google Cloud Platform.</p>
<p><strong>Current status:</strong> Customer accounts, branded Amazon SES mail, staff invites, kitchen assignment, and <code>mfcuisine.se</code> host mapping. Guests can still check out without an account. Status, account, and invite emails use premium HTML templates (SES when keys are set; mock locally).</p>
<p>Meal photographs must be real kitchen photos uploaded by an admin. The storefront never ships AI-generated food. Until a photograph is uploaded, customers see a branded treatment from the kitchen.</p>

<h2>Local setup</h2>
<p>Requirements: Node 22, Java 21 (Firestore emulator), npm.</p>
<pre><code class="language-bash">cp .env.example .env.local
npm install
npm run emulators   # in a second terminal
npm run dev
</code></pre>
<p>Never point local development at a production Firebase project.</p>
<h2>GCP showcase</h2>
<p>The same app runs on Cloud Run for a team demo. Firestore holds the menu and orders; Cloud Storage holds photographs. Payments and delivery stay mocked until Stripe and Wolt keys exist. You need a GCP project with billing enabled, then:</p>
<pre><code class="language-bash">gcloud auth login
GCP_PROJECT_ID=your-project-id ./scripts/gcp-showcase-deploy.sh
</code></pre>
<p>See <a href="DEPLOYMENT.md">DEPLOYMENT.md</a> for what we need from you and for GitHub Actions deploy.</p>
<p>Useful commands:</p>
<pre><code class="language-bash">npm run lint
npm run typecheck
npm test
npm run test:rules
npm run build
</code></pre>
